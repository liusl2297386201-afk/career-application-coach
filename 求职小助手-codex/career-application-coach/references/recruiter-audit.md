# Complete Recruiter Audit

Use for a resume-only request. Deliver a usable audit case before questions; do not turn it into an empty intake conversation.

## Baseline audit v0

Return these sections in order:

1. `30-second judgment`: intended role and level visibility, strongest differentiation, and the earliest real screen-out risk.
2. `Career narrative`: whether the experience order and role logic form a credible route; distinguish deliberate emphasis from confusing chronology.
3. `Value evidence`: for each core experience, extract known context, objective, judgment, action, collaborator, delivery object, affected party, scope, mechanism, metric, and result.
4. `What must remain`: module titles, data, delivery objects, or rare evidence that must not be compressed away.
5. `Actual screening risks`: only issues grounded in the source, each with source evidence, why it affects screening, and a remedy.
6. `Candidate revision priorities`: the smallest factual changes with a visible gain; do not rewrite the entire resume unless requested.
7. `Interview and direction preview`: likely follow-up themes, the current strongest target direction, one adjacent direction, and the next evidence-building action.

## Question boundary

Only after the seven sections, ask at most three to five evidence-upgrade questions. Each question must reveal a decision, trade-off, delivery object, affected party, result, or repeatable method, and name which audit conclusion, rewrite, interview answer, or portfolio case it could upgrade.

Do not call a missing item evidence that the user lacks the experience. Use `evidence insufficient` or `needs confirmation`.
