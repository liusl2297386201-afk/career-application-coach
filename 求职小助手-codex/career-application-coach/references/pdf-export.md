# Optional PDF Export

Use only after the user explicitly agrees to receive a PDF of a complete v0 or upgraded report. Read the PDF skill before creating the file.

## Content and scope

- Export the complete current report: conclusion, capability analysis, evidence match, STAR cases, candidate rewrites, interview material, portfolio plan, action plan, and any current `补充说明` questions.
- Preserve fact, inference, candidate wording, and evidence-gap labels. Do not silently omit sections to reduce page count.
- Do not create an HTML file as an intermediate deliverable or alternative output.

## Layout

- Use a restrained A4 report layout with a title, version label, date, clear heading hierarchy, readable Chinese font fallback, page numbers, generous margins, and sensible page breaks.
- Use tables only for true comparisons. Split dense tables across pages or convert them into short lists when needed for legibility.
- Use no decorative theme, illustrations, dashboard cards, hero image, ornamental graphics, or nonessential screenshots. The only purpose of layout is complete, orderly reading.

## Verification

- Generate with a reliable PDF workflow, render every page to images, and inspect alignment, page breaks, table clipping, Chinese glyphs, and legibility.
- Keep the final file in the user-scoped output location and report its path only after visual verification succeeds.
