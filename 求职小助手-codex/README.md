# 求职小助手

面向中文求职场景的 Codex Skill：基于真实经历，完成简历审计、JD 匹配、针对性改写、面试准备、作品集案例规划与近期求职行动建议。

它的核心原则是：先给出可直接使用的完整分析，再用少量追问补强证据；不把材料未写清误判为没有做过，也不编造指标、职责、预算、ROI 或项目成果。

## 适用场景

- 简历审计与针对性优化
- 简历 + JD 的投递判断与完整申请案例（v0）
- 经历梳理、STAR 面试准备与深度追问
- 游戏发行、内容发行、社区、达人/主播、独游等岗位的材料分析
- 作品集案例页规划与近期职业行动建议

## 核心工作方式

当同时收到简历与 JD 时，Skill 会先完成一份 `v0` 申请案例，再提出 3–5 个只会影响特定模块的“证据升级追问”。v0 固定涵盖：

1. 岗位本质与 30 秒投递判断
2. 岗位所需能力拆解
3. 岗位与经历匹配度
4. 核心案例与 STAR
5. 简历改写建议
6. 经历追问，提炼精华
7. 作品集案例方案
8. 职业路径规划&近期行动目标

候选改写会保留原材料中有价值的模块、指标、平台、协作者、交付物、机制与结果，并说明 `revision gain`；不会为了“精简”而削弱经历竞争力。

每个完整版本输出后，Skill 会按需询问是否整理为 PDF；用户未明确同意时，不会生成 PDF 或 HTML 文件。

## 安装到 Codex

1. 下载并解压本仓库。
2. 将 `career-application-coach` 文件夹复制到你的 Codex Skills 目录：
   `C:\\Users\\<你的用户名>\\.codex\\skills\\`
3. 重启或刷新 Codex，让它重新加载 Skills。
4. 在对话中使用 `$career-application-coach`，或直接说“用求职小助手分析我的简历和 JD”。

Codex 中显示名称为“求职小助手”；文件夹名与调用名保留为 `career-application-coach`，以保证安装和调用稳定。

## 隐私与使用边界

- 本仓库不包含任何真实简历、JD、项目截图、聊天记录或测试输出。
- 请勿提交个人联系方式、身份证明、公司保密资料、未公开数据或客户信息。
- `.gitignore` 已默认排除常见个人材料、导出文件、缓存和密钥文件；上传前仍建议在 GitHub 的提交文件列表中再检查一次。
- 该 Skill 只基于提供的材料和用户确认信息输出候选建议，不替代用户对事实、保密义务与投递内容的最终审核。
